# Barbershop Website — Barbearia Barão

## Overview

A responsive barbershop website built with WordPress, Elementor and dynamic-content plugins. The project brings together service discovery, professional profiles, business information and a multi-step appointment booking experience in a consistent black-and-gold visual identity.

## My Contributions

- Developed and customized responsive pages with **WordPress** and **Elementor**.
- Configured **service and professional listings** using WordPress content management and **JetEngine**.
- Integrated an **appointment booking workflow** using **LatePoint** in the original WordPress environment.
- Customized the website and integrations using **HTML, CSS, JavaScript and PHP**.
- Worked with plugin configuration and layout adjustments across desktop and mobile views.

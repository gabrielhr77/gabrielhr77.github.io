# ASD GameHub — Inclusive Educational Games

**Project:** Software para a Sociedade (S2S), University of São Paulo (USP)  
**Format:** Collaborative university extension project  
**My role:** Developer of two of the application's three educational games  
**Original team repository:** [v1n1btt/ASD_GameHub](https://github.com/v1n1btt/ASD_GameHub)

## Overview

ASD GameHub is a collaborative educational application designed with autistic children in mind. Developed in the context of a university extension activity, the project combines interactive games, visual elements, and simple navigation in a Python/Kivy application.

The application includes three games: Social Understanding, Daily Routines, and Emotional Memory. **My individual contribution was developing Social Understanding and Daily Routines**. The project and its other components were developed collaboratively by the team.

## My Contributions

### Social Understanding (Leitura Social)

- Implemented gameplay based on **20 everyday social scenarios**.
- Built interactions in which the player selects a response and receives contextual feedback.
- Incorporated visual reactions and character selection into the game experience.
- Worked with Kivy screens, UI components, and game-state transitions.

### Daily Routines (Rotina do Dia)

- Developed a sequencing game covering **five everyday routines**.
- Implemented activities in which players organize steps of daily tasks.
- Integrated images, interactive controls, and progress feedback.
- Separated routine data from the interface and gameplay logic.

## Technical Implementation

The application is implemented in **Python** using **Kivy** for graphical interfaces. Its main application uses `ScreenManager` and transitions to navigate between menus, games, and completion screens. Game content is organized in Python modules, while graphical assets are stored separately.

The repository includes a `buildozer.spec` configuration for Android packaging. The presence of this configuration does not, by itself, establish that a distributable APK has been published.

## Collaboration and Context

This was a **team project**, not a solo application. My work covered two games; the broader application and the Emotional Memory game were developed with contributions from other team members.

The project was created as an educational software initiative. No claims about clinical effectiveness or formal validation are made here.
